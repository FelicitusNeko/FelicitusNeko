# AI Policy

- FelicitusNeko will not knowingly commit LLM-generated code to his repositories.
  - If he discovers any LLM-generated code committed on his behalf, he will seek to remove/revert it as soon as possible.
- FelicitusNeko will not knowingly accept pull requests containing LLM-generated code.
  - If he discovers any such pull requests, any merged requests will be reverted as soon and as best as possible, and the submitting user will be warned or barred from further contributions as appropriate.
- FelicitusNeko will avoid contributing to third-party repositories which prominently feature LLM-generated code.
- A best reasonable effort will be made to avoid third-party libraries and dependencies which prominently feature LLM-generated code.
  - Issues may be posted to projects which use such libs/deps. Please suggest an alternative if possible.
  - As time goes on, it may become more difficult to completely avoid libs/deps containing LLM-generated code. Removing and/or reimplementing functionality to remove a lib/dep without a replacement will generally only be done as a last resort.
